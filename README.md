# My Company Site

A simple one‑page website template for a company or project.

---

## About
This repository contains a small static website (HTML + CSS). It is intended to be a quick landing page you can edit and publish with GitHub Pages.

## View the site
After you add or update files:
1. Go to the repo Settings → Pages.  
2. Under Source select Branch: `main` and Folder: `/ (root)`. Save.  
3. Open the provided URL (usually `https://your-username.github.io/your-repo-name`).

## How to edit
- Edit `index.html` to change the text (company name, tagline, About).
- Edit `style.css` to change colors and layout.
- Commit changes in the GitHub web editor or push from your computer.

## Quick start (for contributors)
1. Fork or clone this repo.
2. Edit files, then commit and push changes.
3. Open a Pull Request to propose changes.
